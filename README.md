# 부산 홍보 대사 — 교사용 안내

초등학교 4학년 사회 「지역을 알리는 자료를 만들어 볼까요?」 수업용 웹앱입니다.
학생 1명이 기기 1대로 처음부터 끝까지 혼자 진행합니다.

- 서버, 로그인, 설치가 필요 없습니다. `index.html`을 열면 바로 실행됩니다.
- 학생이 쓴 내용은 그 기기의 브라우저에만 저장됩니다. 외부로 보내는 정보는 없습니다.
- 글꼴(학교안심 둥근미소, 프리텐다드)만 인터넷에서 내려받습니다. 인터넷이 안 되면 기기의 기본 글꼴로 보이고, 나머지 기능은 그대로 동작합니다.

## 파일 구성

| 파일 | 내용 | 교사가 고칠 일 |
|---|---|---|
| `index.html` | 앱을 여는 파일 | 없음 |
| `js/config.js` | 교사 설정 | 스크랩 조건, 퀴즈 문항 수, 보성 녹차 예시 |
| `data/articles.js` | 부산 기사 21개 | 기사 글, 사진, 원문 링크, 퀴즈 |
| `data/methods.js` | 알리는 방법 6개 | 특징 문장, 도움말, 퀴즈 |
| `css/style.css` | 화면 디자인 | 없음 |
| `js/app.js` | 앱 동작 | 없음 |

파일은 메모장이나 VS Code로 열어 고치고, 저장한 뒤 브라우저를 새로고침하면 적용됩니다.

## 수업 전에 확인할 것

1. **보성 녹차 예시**: `js/config.js`의 `examples`는 교과서 문장을 그대로 옮긴 것이 아니라 비슷하게 새로 쓴 글입니다. 교과서와 똑같이 맞추려면 이 부분을 고쳐 주세요.
2. **기사 내용**: `data/articles.js`의 기사는 이 앱을 위해 새로 쓴 학습용 기사입니다. 수치와 연도는 넣지 않았습니다. 수업 전에 한 번 읽어 보고 학급에 맞게 고쳐 주세요.
3. **사진과 원문 링크**: 처음에는 모두 비어 있어 그림(이모지)만 나옵니다. 아래 방법으로 넣을 수 있습니다.

## 기사·링크·사진 바꾸는 방법

`data/articles.js`를 엽니다. 기사 하나는 `{ ... }` 한 덩어리입니다.

```js
{
  id: "haeundae",              // 기사마다 다른 영어 이름 (겹치면 안 됨)
  category: "nature",          // nature 자연환경 | culture 역사·문화 | product 생산물
  title: "해운대해수욕장",
  body: "본문 3~4문장",
  district: "해운대구",
  feature: "특징 한 줄",        // 퀴즈 풀이에 나옵니다
  story: "역사 또는 이야기 한 줄",
  goodPoint: "좋은 점 한 줄",
  imageUrl: "",                // 사진 주소
  sourceUrl: "",               // 실제 기사 주소
  sourceName: "",              // 출처 이름
  emoji: "🏖️",                 // 사진이 없을 때 나오는 그림
  aliases: ["해운대"],          // 퀴즈에서 ○○○로 가릴 다른 이름
  quiz: []
},
```

- **원문 링크 넣기**: `sourceUrl: "https://..."`, `sourceName: "○○신문"`처럼 적습니다. 주소를 넣은 기사에만 "원문 보기"가 나타납니다.
- **사진 넣기**: 프로젝트에 `images` 폴더를 만들어 사진을 넣고 `imageUrl: "images/haeundae.jpg"`처럼 적습니다. 인터넷 주소(`https://...`)도 됩니다. 직접 찍은 사진이나 사용이 허락된 사진만 써 주세요.
- **기사 추가**: 덩어리 하나를 복사해 붙이고 `id`를 새 이름으로 바꿉니다. 덩어리 사이의 쉼표(`,`)를 빠뜨리지 마세요.
- **기사 삭제**: 덩어리 하나를 통째로 지웁니다. 분류마다 4개 이상은 남겨 두어야 퀴즈 보기가 잘 만들어집니다.
- `feature`, `story`, `goodPoint`는 학생의 표에 자동으로 채워지지 않습니다. 학생은 기사를 읽고 직접 씁니다.
- 글 안에 큰따옴표(`"`)를 쓰려면 `\"`로 적습니다.

## 퀴즈 문항

퀴즈는 기사와 알리는 방법 데이터에서 자동으로 만들어집니다. (무엇인지 맞히기, 분류 맞히기, 초성 퀴즈, 방법 맞히기, OX 퀴즈)

직접 만든 문항을 넣으려면 기사나 방법의 `quiz: []` 안에, 또는 `data/methods.js` 아래쪽 `EXTRA_QUIZ`에 적습니다.
직접 넣은 문항은 한 번에 영역별로 2개까지 섞여 나옵니다.

```js
// 4지선다: answer는 정답의 순서 (첫 번째가 0)
{ question: "기장 미역을 말릴 때 쓰는 것은?", options: ["햇볕과 바람", "냉장고", "전자레인지", "난로"], answer: 0, explain: "줄에 널어 햇볕과 바람에 말려요." }

// OX: 맞으면 true, 틀리면 false
{ question: "밀면은 메밀로 만든 면이다.", ox: false, explain: "밀면은 밀가루로 만든 면이에요." }
```

## 설정 바꾸는 방법

`js/config.js`를 엽니다.

| 설정 | 뜻 | 처음 값 |
|---|---|---|
| `scrapMin` | 2단계에서 스크랩해야 하는 기사 수 | 3 |
| `quizCount` | 4단계 퀴즈 문항 수 | 10 |
| `storageKey` | 학습 기록을 저장하는 이름 | `busanPR_v1` |
| `examples` | "예시 보기"에 나오는 보성 녹차 예시 | — |

같은 기기를 다른 반이 이어서 쓴다면, 학생이 화면 오른쪽 위의 **처음부터 다시**를 눌러 기록을 지우고 시작하게 해 주세요.

## 학생 배포 방법

**방법 1. 인터넷 주소로 나누어 주기 (태블릿에 알맞음)**
폴더 전체를 GitHub Pages, Netlify 같은 정적 호스팅에 올리고 주소나 QR 코드를 알려 줍니다. 폴더 구조를 그대로 올려야 합니다.

**방법 2. 파일로 나누어 주기 (PC실에 알맞음)**
폴더 전체를 압축해 학생 PC에 복사하고, 압축을 푼 뒤 `index.html`을 크롬이나 엣지로 엽니다.

**알아 둘 점**

- 기록은 기기와 브라우저마다 따로 저장됩니다. 다음 시간에 이어서 하려면 같은 기기, 같은 브라우저를 써야 합니다.
- 브라우저의 방문 기록(쿠키와 사이트 데이터)을 지우면 학습 기록도 지워집니다. 시크릿 창에서는 창을 닫으면 사라집니다.
- 6단계와 7단계의 **이미지 저장**은 기기의 다운로드 폴더에 PNG 파일로 저장됩니다. **인쇄**는 브라우저의 인쇄 창을 엽니다.
- 발표자료를 실제로 만드는 도구는 앱에 들어 있지 않습니다. 6단계까지 마치면 선생님이 따로 안내해 주세요. 학생은 설계도의 "글 복사", "설계도 전체 복사"로 쓴 글을 옮길 수 있습니다.
